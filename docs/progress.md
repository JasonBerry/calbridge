- M6 (2026-11-19): `translate.VTimezone` generates deterministic VTIMEZONEs from Go's embedded tzdata via ZoneBounds (STANDARD/DAYLIGHT per distinct transition, DTSTART + RDATEs, span = year before start to year after end); `emit_vtimezone: true` now embeds one per TZID used (config stays false per P0-8). `ResolveZone` maps Windows/legacy names (e.g. "AUS Eastern Standard Time") to IANA; unknown zones render as UTC.
